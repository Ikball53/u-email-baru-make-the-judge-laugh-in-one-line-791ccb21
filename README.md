# The Strongest Coffee

A one-line joke for the "Make the Judge Laugh in One Line" bounty.

The entry is a deadpan coffee-shop gag: an exhausted customer asks the
barista for the strongest coffee she has, and instead of a cup she just
slides a mirror across the counter — the strongest thing on offer is the
customer's own face. The setup promises a drink, the payoff breaks that
expectation, and the laugh lands on the final image with nothing
explained after it.

`main.py` (Python 3, standard library only) writes that single line to
`entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default
`/output`). The output is deterministic: two runs produce byte-identical
files, and the script asserts the line is exactly one line of 1–200
characters.

## Run

```sh
python3 main.py
```
